# Безопасность

Учебная копия и публичное демо работают без входа. Кто открыл адрес, видит и меняет общие данные. Настоящие реквизиты, документы и пароли туда не вводите.

Сообщение об уязвимости отправляйте через Security Advisories этого репозитория. В публичный issue не кладите секрет и данные людей.

CSV проверяется по типу, размеру и содержимому. Тело запроса ограничено. Чужой сайт не может отправить форму: у изменяющих запросов есть свой заголовок, а CORS выключен.
